菜单面板不再只是「一列按钮」：.gh-menu__heading 是分组小标题，.gh-menu__divider（或 <hr>）画通栏分隔线，gh-menu-item expandable 配一个 .gh-menu__sub 就是可折叠的下一级，active 显示为「灰底胶囊 + 左侧强调条」的当前项，顶层项与嵌套项的胶囊同宽，缩进只加在文字上，强调条落在同一条竖线上、与胶囊恒留 4px 缝（统一 3×20、行左缘外侧 7px）。选中子项后该组会自动收起（再点父项可重新展开）。<gh-menu> 是独立面板，加 plain 可去掉外壳直接嵌在侧栏或卡片里；放在 gh-dropdown / gh-select 弹层里仍可继续用 div.gh-menu。

同一套行外观被 gh-menu-item、gh-nav-item、gh-popover-item、gh-option、gh-list-item 和自定义行共用：语义只认 aria-current="page"（当前项）、aria-selected="true"（选中）、.is-cursor（键盘游标），颜色与几何全部来自 --gh-row-* 令牌（--gh-row-bg-current / --gh-row-bg-selected / --gh-row-bg-cursor / --gh-row-bar-color / --gh-row-bar-inset / --gh-row-height / --gh-row-gap / --gh-row-radius …）。给任意元素加 class="gh-row" 就是一行：不用写一行 CSS，左侧强调条默认落在行左缘外侧 7px（3px 宽 → 与胶囊 4px 缝、20px 高），菜单 / 嵌套项 / plain / 侧栏展开与折叠 / 导航行 / 自定义行都是同一位置（条离容器内缘 5px、胶囊 12px）；弹层里的勾选列表不画条，选中与否只看 16px 复选框；面板左右内边距由 --gh-menu-pad-x（默认 12px）控制，侧栏轨道由 --gh-sidebar-gutter（16px）控制，容器内边距不足时改一个 --gh-row-bar-inset 即可。

快速原型

用干净的、可组合的 building block 拼出自定义模型，不必从零写一遍训练循环：

  • Attention 变体：GQA、QK Norm、K=V Attention、Gated Attention 开箱可用。
  • 灵活的归一化：RMSNorm、Zero-Centered RMSNorm 与 Conditional 版本。
  • 位置编码：RoPE、ALiBi、相对位置，一行配置切换。
  • MoE：Top-k 路由、负载均衡损失、专家并行都在同一套接口下。

每个模块只声明「输入形状 → 输出形状」和参数，剩下的并行切分、混合精度、激活重算由框架统一处理，所以同一个模型既能在单卡跑，也能直接扩展到多机多卡。
